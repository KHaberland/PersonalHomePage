# Страница «Главная» (Home)

**Маршрут:** `/[locale]` — локали `en`, `ru`, `lv` (например `/ru`, `/en`).
**Код страницы:** `frontend/app/[locale]/page.tsx`.
**SEO (пример, RU):** заголовок и описание из `seo.homeTitle` / `seo.homeDescription` в `frontend/messages/*.json` (через `createPageMetadata`).

Ниже — **порядок блоков** и **актуальные тексты интерфейса на русском** (namespace `home`; где нужно — `common`, `about`, `experience`). Часть контента **подставляется с API** (биография, фото, книга, опыт, калькуляторы, статьи блога); при отсутствии данных показываются строки из `messages` или встроенные fallback (см. `frontend/lib/fallback-content.ts`).

**HTML в переводах:** для вставки в `dangerouslySetInnerHTML` в коде используется `t.raw(...)` (next-intl), иначе теги вроде `<p>` воспринимаются как ICU-плейсхолдеры.

## Технические примечания

- Язык интерфейса — префикс маршрута (`ru`, `en`, `lv`).
- Переводы главной — **`frontend/messages/<locale>.json`**, основной объект **`home`**; навигация справа — **`common`**.
- Секции используют общий компонент **`Section`**: классы `section`, `scroll-mt-24`, опционально `border-t border-border`, контейнер `container-wide`.
- Сжатое соответствие блоков ТЗ и ключам JSON зафиксировано в **`correction.md`**.
