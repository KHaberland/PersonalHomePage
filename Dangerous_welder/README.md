# DANGEROUS WELDER: THE LAST SHIFT

Папка концепции и плана браузерной игры. Кода игры здесь пока нет.

**Статус:** концепция.  
**Старт разработки:** после завершения и запуска основного инженерного сайта.  
**Девиз:** «Его хотели заменить роботами. Теперь роботам нужна замена».

Жанр: 2D-платформер / шутер / промышленная комедия.  
Стиль: ретроигры 90-х, современный пиксель-арт.  
Платформы: браузер на Windows, Android и iOS.

## Принцип

Сначала игра, в которую хочется играть ещё минуту. Управление, бой и шутка важнее архитектуры. Первая версия — один уровень на 3–5 минут.

Игра живёт в этой папке. Она не становится приложением Django, маршрутом Next.js и не использует API сайта.

Рабочий порядок: никаких совещаний, отчётов и согласований вокруг этой папки. Следующий шаг после запуска сайта — этап 1 в [plan.md](plan.md).
