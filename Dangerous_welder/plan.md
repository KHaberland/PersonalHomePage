# Поэтапный план реализации

Игра: **DANGEROUS WELDER: THE LAST SHIFT**.  
Канон сюжета, оружия и реплик: [concept.md](concept.md).  
Сейчас в папке только документы. Код появляется на этапе 1, после запуска основного инженерного сайта.

Принцип прохождения этапов: каждый этап заканчивается тем, что можно запустить и потрогать. Следующий этап начинается, когда предыдущий уже приятен. Если прыжок бесит, новые роботы его не спасут.

## 0. Условие старта и границы

Разработка начинается после завершения и запуска инженерного сайта. До этого папка не обрастает `package.json`, ассетами и экспериментами «на полчаса».

Игра — отдельное статическое приложение внутри `Dangerous_welder/`. Сайт (`frontend/`, `backend/`) ради неё не меняется.

В MVP входит:

- один уровень на 3–5 минут по маршруту «душ → закрытый выход → цех → роботы → склад»;
- бег, прыжок, непрерывное пламя пропановой горелки;
- кислород и пропан как два ресурса;
- наземный робот-сварщик и инспекционный дрон;
- реплики из раздела «Реплики MVP» в [concept.md](concept.md);
- клавиатура и сенсорные кнопки;
- внутренний холст 640×360, цель 60 кадров в секунду.

После MVP, отдельными этапами:

- ацетилен, плазма, лазер;
- водородная горелка остаётся выключенным режимом в данных первой версии;
- ремонтники, погрузчики, лазерные роботы, боссы и центральный ИИ;
- резка препятствий, захват складов, несколько цехов;
- музыка, нормальный пиксель-арт, PWA.

Стек этапа 1 и дальше: TypeScript, Vite, Canvas 2D, свой цикл, JSON-уровни. Физическая библиотека, React, Django и база данных в эту папку не добавляются.

## 1. Окно, цикл, масштаб

Цель: пустой цех, который уже держит 60 кадров и правильно лежит на любом экране.

Сделать:

- `package.json`, `tsconfig.json`, `vite.config.ts`, `index.html`, `src/main.ts`, `src/engine/loop.ts`, `src/engine/canvas.ts`.
- В `vite.config.ts` поставить `base: "./"`, чтобы сборка открывалась как папка статических файлов.
- Холст рисует в буфере 640×360 и растягивается на окно с полями по краям. Для целых масштабов 2× и 3× включить `image-rendering: pixelated`.
- Цикл: `requestAnimationFrame`, фиксированный шаг симуляции 1/60, запас шагов за кадр ограничен, чтобы лаг не превращался в вечную догонялку.
- Счётчик кадров в углу, выключается флагом.

Команды, когда этап начат:

```powershell
Set-Location .\Dangerous_welder
npm install
npm run dev
```

Сборка позже:

```powershell
npm run build
```

Критерий выхода: окно открывается, холст не мылится на целом масштабе, счётчик держится около 60 на компьютере. Документы `README.md`, `concept.md` и `plan.md` остаются на месте.

## 2. Сварщик бегает и прыгает

Цель: тридцать секунд бега по плоскому полу уже хочется повторить. Врагов ещё нет.

Сделать:

- `src/game/player.ts`, `src/engine/input.ts`, `src/tuning.ts`.
- Прямоугольник-герой. Спрайт подставится позже, хитбокс останется.
- Влево, вправо, прыжок. В воздухе горизонтальная скорость сохраняется.
- Гравитация и земля через AABB.
- Койот-тайм и буфер прыжка: прыжок с края платформы и нажатие чуть заранее срабатывают. Высота прыжка зависит от того, как долго зажата кнопка.
- Лицом в сторону последнего движения. Стрельба потом возьмёт это направление.
- Все числа — в `src/tuning.ts`. Логику прыжка ради «чуть выше» не переписывать.

Черновые числа для 640×360, тайл 16 px. Их крутят на этапе 10, в код уровня они не зашиваются:

| Параметр | Старт |
| --- | --- |
| Скорость бега | 130 px/с |
| Высота прыжка | около 52 px, три тайла с запасом |
| Койот-тайм | 0,10 с |
| Буфер прыжка | 0,10 с |
| Хитбокс | 14×28 px |

Клавиатура MVP: стрелки или `A`/`D`, прыжок `Space` / `W` / `K`, огонь `J` или `X`. Сенсорные кнопки — этап 9, раскладка клавиш к тому моменту уже стабильна.

Критерий выхода: разгон, остановка и прыжок на плоском поле предсказуемы. Герой не прилипает к полу и не проваливается.

## 3. Серый уровень и камера

Цель: маршрут от душа до склада можно пробежать без боя и без финальной шутки.

Сделать:

- `src/engine/tiles.ts`, `src/engine/camera.ts`, `src/content/levels/level-01.json`.
- Тайл 16×16. В JSON: ширина, высота, слои `solid` и `deco`, список объектов (дверь, горелка, баллоны, враги, зоны реплик, финиш).
- Камера с мёртвой зоной и небольшим забеганием вперёд по взгляду. Игрок не приклеен к центру.
- Типы тайлов MVP: пусто, твёрдый, платформа (прыжок снизу проходит, сверху держит), конвейер с постоянным сдвигом по X.
- Лестницы в первом уровне не обязательны. Вертикаль закрывают платформы. Лестницы возвращаются вместе со вторым цехом.
- Одна контрольная точка: сразу после подбора горелки. Смерть до неё возвращает в душ. Смерть после — к горелке, газ на момент точки восстанавливается вместе с ней.

Карта на 6–8 экранов, примерно 3500–4500 px в ширину с одной вертикальной развилкой. Дольше пяти минут бежать её без остановок не нужно.

```
[душ]--коридор--[выход заперт, охранник]
   |
   +--[цех: горелка, O2, пропан]
         |
         +--яма, платформы, конвейер
               |
               +--[склад: плакат, пропан, нет ацетилена, финиш]
```

Охранник стоит у двери и патрулирует только коридор выхода. Проход обратно в цех свободен. До горелки коридор даёт место развернуться и убежать в цех.

Критерий выхода: от душа до финишного тайла склада можно дойти прыжками. Конвейер сдвигает, и с него можно спрыгнуть. Камера не показывает пустоту за краем карты.

## 4. Горелка, кислород и пропан

Цель: пламя понятно на вид и по расходу. Оружие следующих этапов добавляется строкой в таблице, а не новым циклом боя.

Сделать:

- `src/game/weapon.ts`, полоски O₂ и C₃H₈ внизу слева.
- Пока зажат огонь и оба ресурса больше нуля, впереди героя держится короткий хитбокс непрерывного пламени.
- Урон тиками, чтобы непрерывное пламя отличалось от выстрела.
- Подбор баллона прибавляет один ресурс. Горелка без газа не стреляет и вызывает реплику `gas.empty` с кулдауном около 8 секунд.
- Конфиг режимов — массив в `src/game/weapons.ts` (или рядом с `tuning.ts`):

```ts
type WeaponMode = {
  id: "propane" | "acetylene" | "hydrogen" | "plasma" | "laser";
  enabled: boolean;
  range: number;
  damagePerTick: number;
  tick: number;
  oxygenPerSecond: number;
  fuelPerSecond: number;
  energyPerSecond: number;
  cuts: boolean;
};
```

В MVP `enabled: true` только у `propane`. У `hydrogen` поле `enabled` остаётся `false`. `cuts` у пропана тоже `false`: в прототипе пламя жжёт роботов и оставляет копоть, металлические стены не режет. Одна сгораемая табличка в цехе допустима, если она ничего не перекрывает.

Черновой баланс пропана, чтобы полного комплекта хватало примерно на 20 секунд непрерывного огня, а уровень требовал ещё одного подбора:

| Параметр | Старт |
| --- | --- |
| Дальность пламени | 56 px |
| Урон за тик | 10 |
| Тик | 0,10 с |
| Расход O₂ | 5 ед/с |
| Расход C₃H₈ | 4 ед/с |
| Полный баллон | 100 ед |
| Первый подбор в цехе | +40 O₂ и +40 C₃H₈ |
| Склад | +70 каждого, ацетилена нет |

Критерий выхода: край пламени виден. На полном первом подборе можно убить двух роботов этапа 5 и почувствовать, что третий уже жадный. Пустой баллон читается по полоске и по реплике.

## 5. Два робота

Цель: обе тактики из канона работают без инструкции на полэкрана.

Сделать:

- `src/game/enemies.ts`, `src/game/projectile.ts`.
- Наземный сварщик идёт к игроку по полу и не прыгает. Дуга короче пламени игрока.
- Дрон зависает, останавливается, 0,5 с мигает и пищит, пускает один заряд, затем 0,8 с уязвим и стоит. Заряд — медленный снаряд, его можно перепрыгнуть.
- У игрока 3 жизни (удара). После удара около 0,8 с неуязвимости. Защитное снаряжение в MVP не подбирается.
- Роботы друг друга не чинят. Ремонтник — отдельный этап после MVP.
- Охранник у выхода использует ту же логику сварщика и не ходит в цех.

Черновик:

| | Игрок, дуга робота | Пламя игрока | Дрон |
| --- | --- | --- | --- |
| Дальность | дуга 28 px | 56 px | снаряд через паузу |
| Скорость | робот 70 px/с | бег 130 px/с | снаряд 140 px/с |
| Живучесть | 140 ед (около 1,4 с в полном пламени) | 3 удара | 70 ед |
| Урон | 1 удар | 10 за тик | 1 удар |

Держать сварщика на краю пламени должно быть выгоднее, чем стоять вплотную. Дрон, которого бьют во время красного мигания, выстрел всё равно выпускает: награда за терпение — пауза после выстрела.

На сером уровне расставить трёх сварщиков и двух дронов. Охранник в это число не входит.

Критерий выхода: новый человек без текста на экране через минуту сам отступает от сварщика и прыгает от заряда дрона.

## 6. Сценарий уровня

Цель: серый маршрут становится сменой. Реплики можно временно заменить подписями зон, тексты подключает этап 7.

Порядок и ориентир по времени умелого прохождения:

| Время | Что происходит | Зона реплики |
| --- | --- | --- |
| 0:00 | Выход из душа, короткий коридор | — |
| 0:20 | Дверь заперта, охранник, путь назад открыт | `exit.admin`, `exit.pass` |
| 0:45 | Цех, горелка на верстаке | `torch.found` |
| 1:00 | Баллоны кислорода и пропана рядом | `gas.first` |
| 1:15 | Первый сварщик на полу | `kill.scrap` после победы |
| 1:40 | Яма и платформы, второй сварщик снизу | пул `fight.*` при затяжном бое |
| 2:20 | Конвейер и третий сварщик | — |
| 3:00 | Два дрона над площадками | `drone.zone`, затем `drone.act` |
| 3:40 | Склад, пустая ячейка ацетилена, плакат, баллоны пропана | `warehouse.supply`, `warehouse.poster`, `warehouse.cheap` |
| 4:00 | Финиш на тайле у плаката | `warehouse.petrovich` |

Финиш срабатывает один раз. Уровень показывает последнюю реплику и останавливает врагов. Бегать в этот момент уже можно, стрелять незачем: склад пуст от роботов.

Вернуться и сжечь охранника можно после горелки. На финиш это не влияет. Отдельная обязательная реплика ему не нужна.

Если умелый прогон короче 3 минут, добавляется одна площадка с роботом. Если длиннее 5 минут, убирается робот или одна яма. Текст не растягивают ради хронометража.

Критерий выхода: уровень проходится от душа до плаката, дверь не открывается, до горелки от охранника можно убежать, контрольная точка помнит героя с горелкой.

## 7. Реплики без остановки игры

Цель: шутка звучит в бою и не превращается в диалоговое окно.

Сделать:

- `src/content/lines.json` — все строки из [concept.md](concept.md) с теми же `id`.
- `src/game/barks.ts` — одна активная реплика. Новая важная заменяет старую. Обычная из пула `fight.*` ждёт, если экран занят.
- Обмен из двух фраз показывается двумя шагами: сначала робот или ИИ (около 1,8 с), затем сварщик (около 2,2 с).
- Полоса субтитров внизу, над полосками газа, крупным читаемым шрифтом. Пиксельный шрифт подключается вместе с артом. До него — системный шрифт без сглаживания на масштабе холста.
- Во время реплики управление остаётся у игрока. Отдельное меню паузы появится вместе со вторым уровнем, если оно вообще понадобится.
- Кулдаун: сюжетная зона срабатывает один раз за забег; `gas.empty` — не чаще раза в 8 секунд; пул боя — не чаще раза в 12 секунд.
- В первый уровень попадают только id из раздела MVP. Строка `warehouse.acetylene` в этот уровень не ставится.

Критерий выхода: на пути к складу игрок видит шутку Петровича, ни одна надпись не требует кнопки «дальше», во время обмена можно прыгать.

## 8. Отклик

Цель: удар, пламя и пустой баллон различимы без полосок, если смотреть на картинку.

Сделать:

- `src/game/particles.ts` с маленьким пулом частиц. В горячем цикле новые объекты на каждый кадр не создавать.
- Пламя: 4–6 тёплых прямоугольников. Попадание по роботу: вспышка хитбокса и искры. Дуга робота: короткая белая полоса, короче пламени. Заряд дрона: яркая точка.
- Попадание по игроку: короткая белая вспышка холста, без долгой тряски камеры. Тряска на 2–3 кадра допустима.
- `src/engine/audio.ts` через Web Audio API. В MVP звуки синтезируются: прыжок, старт пламени, тик пустого баллона, писк дрона перед выстрелом, глухой удар. Файлы музыки не подключаются.
- Звук стартует после первого нажатия клавиши, как того требует браузер.

Критерий выхода: с выключенными подписями полосок всё ещё понятно, горит ли горелка и когда дрон сейчас выстрелит. На компьютере кадры не проседают из-за частиц.

## 9. Сенсорные кнопки и телефон

Цель: тот же уровень проходится пальцем.

Сделать:

- Четыре кнопки поверх холста, не внутри игрового буфера: влево, вправо, прыжок, огонь. Зона нажатия больше рисунка кнопки.
- Кнопки полупрозрачные и сидят в нижних углах, центр экрана свободен под героя и пламя.
- Одновременные касания: бег и прыжок, бег и огонь.
- Клавиатура на телефоне не требуется. На компьютере кнопки прячутся.
- Проверка в мобильной ширине окна браузера и на реальном телефоне, если он есть под рукой. Смотреть портрет и альбом. Альбом — основной: игра широкая, 640×360.

Критерий выхода: маршрут склада проходится только кнопками. Прыжок не срывается из-за того, что палец задел огонь. Субтитры не прячутся под кнопками.

## 10. Плейтест MVP и решение, что крутить

Цель: честный ответ, приятны ли управление, бой и шутка. Новые механики на этом этапе не добавляются.

Протокол, один проход на клавиатуре и один на кнопках:

1. От охранника можно убежать, не умерев.
2. Прыжок попадает туда, куда целился, на первой или второй попытке.
3. Край пламени читается, сварщика удаётся держать на этом крае.
4. Заряд дрона узнаётся до того, как прилетел.
5. Газ успевает кончиться хотя бы один раз до склада, и это смешно, а не наказание на полминуты безоружной ходьбы.
6. Финальная шутка про Петровича замечается без остановки.
7. Ни одна реплика не блокирует шаг.
8. Секундомер умелого прогона лежит между 3 и 5 минутами.
9. Кадры на телефоне остаются плавными. Если частицы виноваты, режется пул, а не разрешение логики.

Крутить только `tuning.ts`, раскладку тайлов и кулдауны реплик. Если провал в управлении — возвращаться к этапу 2. Если провал в бое — к этапу 5. Если финал не смешной — править строки в `lines.json` и [concept.md](concept.md), сохраняя те же `id`.

MVP готов, когда протокол проходит, и ещё один забег запускается сам, без списка задач. После этого игру можно показать. Следующий цех начинается только тогда.

Запуск собранной папки локально:

```powershell
Set-Location .\Dangerous_welder
npm run build
Set-Location .\dist
python -m http.server 4173
```

Если `python` не открывает нужную команду, использовать установленный на машине статический сервер той же папки `dist`. Игру отдавать как статику. Отдельный сервер приложения ей не нужен.

## 11. Очередь после MVP

Порядок такой, потому что каждый пункт опирается на уже проверенный бой. Параллельно можно рисовать спрайты: они не блокируют следующий пункт, пока хитбоксы не меняются.

1. **Пиксель-арт героя, двух роботов, горелки и цеха.** Спрайт-листы вместо прямоугольников. Хитбоксы из `tuning.ts` остаются, пока арт не требует другого размера.
2. **Ацетилен.** Включить режим `acetylene`: длиннее пламя, выше урон, быстрее расход, меньший баллон. Переключение режима одной кнопкой. Первый настоящий баллон C₂H₂ лежит на новом складе, и только там играет `warehouse.acetylene`.
3. **Второй цех.** Новая карта, те же враги, другие платформы. Объявление ИИ из канона — одна зона на цех, не все сразу.
4. **Ремонтный робот.** Чинен повреждённого сварщика, если того не добили. Игрок выбирает, кого гасить первым.
5. **Резка.** У режима с `cuts: true` пламя или плазма снимает помеченные тайлы. Пропан по-прежнему металл не берёт: это повод найти другой режим.
6. **Плазма и лазер.** Общий аккумулятор, отдельные строки конфига. Лазерный робот и реплики `banter.*` / `laser.need-me` приходят вместе с лазером.
7. **Погрузчик и лестницы.** Медленный толчок и вертикальные маршруты.
8. **Босс цеха, затем центральный ИИ.** Короткая арена, без длинной катсцены. Финал игры закрывает реплика `ending.overtime`.
9. **Музыка и записанные звуки.** Заменяют синтез точечно. Юмор остаётся текстом: озвучка героя не требуется, чтобы шутка работала.
10. **PWA.** Манифест, иконка, service worker на файлы сборки. После этого смена играется без интернета. Сервер сохранений не появляется.

Водородный режим в эту очередь не ставится, пока для него нет отдельного решения. Поле в конфиге уже есть и остаётся выключенным. Реплика `warehouse.hydrogen` ждёт полку, где баллон есть, а горелки под него нет.

`src/tuning.ts` — единственное место для скоростей, урона и расхода газа. `lines.json` — единственное место для текстов. Уровень ссылается на id реплик и id типов врагов.

Проверки формул столкновения и расхода газа имеет смысл держать рядом маленьким набором тестов на чистых функциях. Весь остальной ответ «игра работает» даёт протокол этапа 10, а не список модульных тестов.

## Что легко сломать, если забыть

- Охранник, который доходит до душа, убивает игрока до появления управления боем.
- Пламя, которое убивает сварщика за один тик, убирает тактику «держать на крае».
- Диалог с паузой превращает шутер в чтение.
- Реплика «беру свои слова обратно» на складе без ацетилена портит шутку Петровича.
- Логика сайта и логика игры в одном приложении. Игра остаётся статическим холстом в этой папке.
